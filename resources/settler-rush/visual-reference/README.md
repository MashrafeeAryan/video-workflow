# Approved visual reference — original Settler Rush

The user selected this first Higgsfield video as the visual benchmark because
of its cinematography and natural-looking human characters. It is the early
"BETRAYAL / 2050: The Last Human Port" version, before "Your Move".

## Files

- [Original finished video](original-settler-rush.mp4): 20 seconds, 720 x 1280,
  portrait, 24 fps. Preserve it as reference footage; do not overwrite it.
- [Frame overview](reference-sheet.jpg): samples at 1, 4, 8, 11, 14 and 17 seconds.
- `reference-01s.jpg` through `reference-17s.jpg`: individual full-resolution
  samples. The 8s/11s frames show the captain and commander; 14s/17s show the
  robot design, guard, architecture and lighting.
- [Recovered original prompts](original-prompts.md): the exact prompts for the
  three Kling 3.0 source clips, including camera framing and dialogue direction.

## What to carry forward

Grounded cinematic photorealism; weathered stone, timber, leather and metal;
amber firelight against desaturated blue shadows; subtle film texture; serious,
understated performances; short, deliberate shots. The captain has short dark
hair, stubble, and a worn brown leather coat. The robots have dark iron bodies,
narrow amber eyes, and brass insignia. Inspect the actual frames for details.

Use supported reference-image or video inputs to guide new generations. A
different model may interpret the same wording differently. Record the model
and reference assets used, and compare actual footage to this benchmark.

For a continuation, keep this cast and setting consistent. For another game or
story, preserve the visual approach while saving separate cast references.
The port attack is fictional narrative framing, not a game mechanic. Refer to
the parent game's README for actual rules. Keep the current AGENTS.md ending,
deception, budget and quality requirements; do not blindly copy the old edit.
